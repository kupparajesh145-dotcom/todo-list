# todo-list
# 📝 To-Do List App (Python)

A simple command-line To-Do List application built using Python.
This project helps users manage their daily tasks by adding, viewing, and removing tasks easily.

---

## 🚀 Features

* ➕ Add new tasks
* 📋 View all tasks
* ❌ Remove tasks by number
* 🔁 Runs continuously until user exits
* 🧠 Beginner-friendly logic using lists and loops

---

## 🛠️ Technologies Used

* Python (Basics)

  * Lists
  * Loops (`while`, `for`)
  * Conditional Statements (`if-elif-else`)

---

## ▶️ How It Works

1. The app displays a menu with options:

   * Add Task
   * View Tasks
   * Remove Task
   * Exit
2. User selects an option by entering a number
3. The program performs the selected action
4. The menu repeats until the user exits

---

## 💻 How to Run

1. Install Python
2. Clone this repository:

   ```bash
   git clone https://github.com/your-username/todo-list-app.git
   ```
3. Navigate to the folder:

   ```bash
   cd todo-list-app
   ```
4. Run the program:

   ```bash
   python todo.py
   ```
